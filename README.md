# proteng-user-mgmt

Gin + MongoDB service handling auth, user accounts, admin actions, and email notifications for ProtEngPlus. Called by [proteng-bff](https://github.com/ProtEngPlus/proteng-bff), consumes job-status events from RabbitMQ to send notification emails.

See [SETUP.md](./SETUP.md) to get it running locally, and [CONTRIBUTING.md](./CONTRIBUTING.md) for commit conventions and pre-commit hooks.
