# proteng-user-mgmt

Service (Gin + MongoDB) จัดการ auth, บัญชี user, งาน admin, และอีเมลแจ้งเตือนของ ProtEngPlus ถูกเรียกจาก [proteng-bff](https://github.com/ProtEngPlus/proteng-bff) และ consume job-status event จาก RabbitMQ เพื่อส่งอีเมลแจ้งเตือน

วิธีรัน local ดู [SETUP.md](./SETUP.md) กติกา commit กับ pre-commit hook ดู [CONTRIBUTING.md](./CONTRIBUTING.md)
